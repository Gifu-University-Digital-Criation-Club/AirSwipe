# AirSwipe 初期構成案

この文書は、Webアプリ実装前に検討していたPython版の初期構成案です。
現在のセットアップと起動方法は、プロジェクト直下の[README](../README.md)を参照してください。

Webカメラで捉えた手のジェスチャを認識し、PowerPointのスライドを操作するためのPythonプロジェクトです。

指パッチン操作は音声を使いません。MediaPipeで得た手の甲・手首領域について連続フレームの画像差分を計算し、回転時に生じる短い差分ピークを検出して次ページ操作として扱う計画です。

## 実装方針

- OpenCVでWebカメラ映像を取得する。
- MediaPipe Handsで手と手首の位置を取得する。
- 手の甲・手首を含む領域のフレーム差分から、回転に伴う急峻な変化を検出する。
- 誤操作を避けるため、差分ピークの収束確認とクールダウン時間を組み合わせる。
- 確定したジェスチャに応じて、PowerPointへページ操作キーを送信する。
