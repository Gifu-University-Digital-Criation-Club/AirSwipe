# AirSwipe 利用ガイド

AirSwipeは、Webカメラで発表者の右腕を認識し、ジェスチャでスライドを操作するアプリです。このガイドでは、アプリを起動した後の基本操作を説明します。インストールや起動が済んでいない場合は、先に[README](../README.md)を参照してください。

## 利用前の準備

- ChromeまたはEdgeでアプリを開きます。
- カメラに上半身と右腕全体が入る位置に立ちます。
- 逆光や極端に暗い場所を避け、腕が背景と区別しやすい環境で利用します。
- PowerPointを読み込む場合は、あらかじめLibreOfficeをインストールします。

## 基本的な使い方

1. 画面右上のデバッグ表示にある「資料読込」を押し、PDFまたはPowerPointファイルを選びます。資料を選ばない場合は、同梱のデモPDFが表示されます。
2. 「カメラ開始」を押します。ブラウザからカメラの使用許可を求められたら、許可してください。
3. 必要に応じて「全画面」を押し、発表を開始します。
4. 右腕を左右へ素早く動かしてスライドを操作します。
5. 終了するときは「システム終了」を押します。終了できない場合は、起動に使ったターミナルで`Ctrl+C`を押してください。

画面右上の「…」を押すと、デバッグ表示を開閉できます。デバッグ表示は、上部をドラッグして移動できます。

## ジェスチャ操作

| 操作 | 動作 |
| --- | --- |
| 右腕を右方向へ振る | 次のページへ進む |
| 右腕を左方向へ振る | 前のページへ戻る |
| 最終ページで、頭の近くに構えた手首をひねる | 画面を黒くする |
| 黒い画面でもう一度手首をひねる | 1ページ目へ戻って表示を再開する |

上下方向の腕振りもジェスチャ入力として認識されますが、現在の標準スライド画面ではページ移動に使用しません。
腕は斜めではなく、できるだけ水平に動かしてください。一度操作した後は、腕を落ち着かせてから次の操作をすると認識しやすくなります。

手首ひねりでは、左右どちらかの手を頭の高さに上げ、指を軽く曲げた状態で短く構えてから、手首をひねります。認識状況はデバッグ表示の「Snap Twist」で確認できます。

## キーボードで操作する

カメラを使わない場合やジェスチャを確認しづらい場合は、キーボードでも操作できます。

- `→`：次のページへ進む
- `←`：前のページへ戻る

上下の矢印キーもジェスチャ入力として認識されますが、現在の標準スライド画面ではページ移動に使用しません。

## 読み込める資料

- PDF（`.pdf`）
- PowerPoint（`.ppt` / `.pptx`、100MB以下）

PowerPointはPC上のLibreOfficeでPDFへ変換してから表示します。アニメーション、動画、画面切り替え効果は再生されません。また、変換結果のレイアウトが元の資料と異なる場合があります。発表前に全ページを確認してください。

## うまく動作しない場合

### カメラを開始できない

- ブラウザのアドレスバー付近にあるカメラ設定を開き、このサイトでのカメラ利用を許可します。
- Zoomなど、カメラを利用しているほかのアプリを終了してから再度試します。
- ページを開き直し、もう一度「カメラ開始」を押します。

### ジェスチャが認識されない

- デバッグ表示のカメラ映像に上半身と右腕が映っているか確認します。
- カメラとの距離や照明を調整します。
- 腕をゆっくり動かし続けるのではなく、左右へ短くはっきり振ります。
- 発表を続ける必要がある場合は、矢印キーで操作します。

### PowerPointを読み込めない

- LibreOfficeがインストールされているか確認します。
- LibreOfficeをインストールした後は、AirSwipeを一度終了して起動し直します。
- 解決しない場合は、PowerPoint側で資料をPDFとして書き出し、そのPDFを読み込みます。

## プライバシー

カメラ映像と読み込んだ資料は、このPC上で処理されます。カメラ映像の録画・保存や、AirSwipeから外部サーバーへの送信は行いません。詳しくは[READMEの「カメラと資料のプライバシー」](../README.md#カメラと資料のプライバシー)を参照してください。
