# ジェスチャ認識要件

## 入出力

- 入力: Webカメラ映像
- 出力: 認識したジェスチャの種類

## 認識対象

| ジェスチャ | 動作 |
| --- | --- |
| 右へ腕を振る | 次ページ |
| 左へ腕を振る | 前ページ |
| ページをめくる動作（右→左） | 次ページ |
| ページをめくる動作（左→右） | 前ページ |
| 指パッチン | 次ページ（オプション） |

## 指パッチンの判定

指パッチンは音声を使用せず、手の甲または手首を回転させた際の手領域の連続フレーム間における画像差分から検出します。短時間に大きな差分が発生し、その直後に差分が収束した場合を指パッチン操作として扱います。

1. MediaPipe Handsで手と手首のランドマークを検出する。
2. 手の甲と手首を含む手領域を切り出し、グレースケール化・軽い平滑化を行う。
3. 現在フレームと直前フレームの絶対差分を取り、差分画素数または差分量を算出する。
4. 手の甲または手首の回転により、設定した閾値を超える急峻な差分ピークを検出する。
5. ピーク後、所定時間内に差分が閾値未満へ戻った場合のみ指パッチンとして確定する。

照明変動や腕全体の平行移動による誤検出を避けるため、手の甲・手首領域に限定して差分を判定します。

## 有効判定

- 同一ジェスチャを一定時間以上継続した場合のみ有効とする。
- 誤認識防止のため、判定後にクールダウン時間を設ける。

```text
ジェスチャ認識 → 500ms以上継続 → PowerPoint操作 → 2秒間受付停止
```
